# fuku_coord (服コーディネートAIアプリ)

手持ちのGジャンやワークパンツなどの手持ち服から、**今日の気候・目的地に合わせてAIが最高のコーディネートと着こなしのコツを提案してくれるWebアプリ**です。

WEBAPL配下の他プロジェクト（`htd-m` や `back_sheet` など）と同じ構成（HTML + CSS + JavaScript + GAS + Googleスプレッドシート）で構築されています。

---

## 🚀 すぐに使う方法（PC・スマホ両対応）

1. `fuku_coord` フォルダ内の [`index.html`](index.html) をダブルクリック（またはブラウザにドラッグ＆ドロップ）して開きます。
2. 最初から **18着のリアルなお出かけ用サンプル服（Gジャン各種、ワークパンツ各種、スウェット、ブーツ等）** が登録されています。
3. 気温や目的地（カフェ、古着屋巡りなど）を選んで **「🤖 AIスタイリストに提案してもらう」** を押すか、**「🎲 今日のおまかせ！」** をワンクリックするだけで、スタイリストからの解説文付きでコーディネートが表示されます。

---

## 🚪 画面から手持ち服を登録・編集する（サブ画面）

スプレッドシートを開かなくても、**アプリ画面上から直接服の追加・編集・削除ができます**：

1. 画面右上の **「🚪 クローゼット管理・服登録」** ボタンをクリック。
2. **「➕ 服を登録・編集」タブ**:
   * カテゴリ（アウター、トップス、ボトムス、シューズ）をワンタップ選択
   * タイプ（Gジャン、ワークパンツ、Tシャツ等）をクイック選択
   * 服の名前、ブランド、カラー、シルエット、適正気温（スライダー）を入力して「保存」するだけ！
3. **「📋 登録済み一覧」タブ**:
   * 現在登録されている服が一覧表示されます。
   * **「✏️ 編集」**：タップするとフォームに値がセットされ、気温やメモを微調整できます。
   * **「🗑️ 削除」**：不要になった服をワンタップで削除できます。
   * **「🔄 初期データに戻す」**：いつでも最初の18着の状態に戻せます。
4. ※ 登録・編集した服はブラウザ内（LocalStorage）に自動保存されるため、ページをリロードしても消えません。

## 📱 スマホで快適に使う方法

1. **PCでのスマホ確認**:
   * ChromeやEdgeで `F12` キーを押し、左上のスマホアイコン（Device Toolbar）をオンにすると、スマホ縦画面での操作感が確認できます。
2. **スマホ実機で使う（おすすめ）**:
   * 本アプリのファイルを Google Apps Script（GAS）にデプロイし、「ウェブアプリURL」を発行すると、スマホのSafariやChromeで開けるようになります。
   * スマホのブラウザで開いて **「ホーム画面に追加」** を押せば、ネイティブアプリのようにホーム画面のアイコンから一発起動できます！

## 🔑 本物のGemini AIと連携する方法（完全無料）

1. [Google AI Studio](https://aistudio.google.com/) にアクセスし、Googleアカウントでログインして「Get API Key」をクリック（無料枠で即時取得できます）。
2. アプリ画面右上の **「⚙️ 設定」** ボタンをクリック。
3. 取得したAPIキーを貼り付けて「設定を保存」をクリック。
4. これ以降、本物のGeminiスタイリストがあなたの手持ち服からコーディネートを考案してくれます！

## 📊 自分の服をスプレッドシートで管理したい場合

1. Googleドライブで新規スプレッドシートを作成し、シート名を `clothes` に変更。
2. 1行目に以下の列名を入力：
   * `id`, `category`, `subcategory`, `name`, `brand`, `color`, `fit`, `tempMin`, `tempMax`, `tags`, `description`
3. メニュー「拡張機能」→「Apps Script」を開き、`app/code.gs` の内容を貼り付け。
4. スクリプト内の `SPREADSHEET_ID` に、スプレッドシートURLのID（`/d/xxxxxx/edit` の部分）を設定。
5. 右上「デプロイ」→「新しいデプロイ」→「ウェブアプリ」として公開。
